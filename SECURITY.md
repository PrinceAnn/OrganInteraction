# Security policy

Please report suspected data disclosure or credential exposure privately to the
repository maintainers. Do not open a public issue containing samples, column
names, storage paths, identifiers, or screenshots of restricted material.

For a suspected disclosure:

1. pause publication and mirroring;
2. preserve evidence without copying restricted content into issue trackers;
3. notify the data steward and repository owner through an approved private
   channel; and
4. treat deletion from the latest commit as insufficient until history, forks,
   caches, and release artifacts have been reviewed.
